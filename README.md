# Python Learning Repository

A clean, modular, and structured repository designed for learning Python fundamentals, data structures, and practical CLI mini-projects.

## 📂 Repository Structure
python-learning/
│
├── basics/
│   ├── variables.py        # Data types, variables, and type conversion
│   ├── conditions.py       # Conditional statements & logical operators
│   ├── loops.py            # For loops, while loops, break & continue
│   └── functions.py        # Function definitions, parameters, and return values
│
├── data_structures/
│   ├── lists.py            # List manipulation, indexing, and slicing
│   ├── tuples.py           # Tuple immutability and unpacking
│   ├── dictionaries.py     # Key-value maps, dict methods, and iteration
│   └── sets.py             # Unique collections and set logic operations
│
├── practice/
│   ├── calculator.py       # Command-line arithmetic calculator
│   └── number_guessing.py  # Interactive CLI number guessing game
│
└── README.md               # Repository documentation
